# Operational World Mapping

Aperture can investigate the same canonical evidence architecture through different operational contexts without creating a different truth system for each domain.

Current public worlds may include:

- Monitoring,
- Workflow Operations,
- Software Engineering,
- Security Operations,
- Cloud Infrastructure,
- Human Attention,
- Evidence Validation.

Operational Worlds may adapt terminology, case selection, operator guidance, investigation emphasis, signal priority, and navigation.

They may not change the canonical runtime, telemetry, authoritative markers, instrument findings, evidence identity, Evidence Seal, or preservation authority.

**Different operational worlds. One canonical evidence architecture.**
