# Aperture Public Implementation Map

The public workstation is organized around an operator flow rather than a collection of independent dashboards.

## Primary navigation

- **Start / Engage**
- **01 Acquire / Observe**
- **02 Structure / Reconstruct**
- **03 Measure / Qualify**
- **04 Investigate / Assess**
- **05 Preserve / Hand Off**
- **Help / Guide**

## Acquire

### Blackbox
Direct deterministic path for loading or pasting supported operational logs/transcripts, qualifying the source, and initiating Runtime Evidence computation.

### Evidence Chamber
Advanced intake environment exposing source routing, source preview, schema/adapter posture, source hash, detected events, event structure/source spans, optional trace/reference context, readiness/coverage, disclosure, calibration, and preflight diagnostics.

### Validation Lab
Registered operational and validation cases across supported Operational Worlds. Validation expectations remain outside canonical evidence formation and are compared only after the canonical runtime is formed.

## Structure / Reconstruct

Forms the replayable runtime evidence representation: event ledger, canonical spine, playback frames, Worldline, runtime/role/failure formation, and reconstruction surfaces.

## Measure / Qualify

Projects telemetry and bounded instrument findings over the shared evidence identity.

## Investigate / Assess

Guided Investigation and evidence review allow operators to move between findings, evidence basis, source coordinates, and claim boundaries without altering the underlying run.

## Preserve / Hand Off

Exports machine-readable Runtime Evidence and preservation bundles after the governing authority and identity checks are satisfied.
