# ESL v2 / Human Read Compatibility Note

The earlier repository described ESL v2 as the primary synthesis surface. In the current Aperture architecture, **Human Read** remains a bounded, evidence-governed presentation layer over the Current Evidence Run and associated registered methods.

## Current posture

Human Read may consume:

- CER identity and source posture,
- regime/marker state,
- metrics and legitimacy metadata,
- bounded instrument findings,
- evidence basis/source spans,
- missingness and claim boundaries.

It may not create evidence, invent narrative authority, promote a candidate to confirmed, or erase uncertainty/absence.

## ESL v2 regime vocabulary

Current public regime vocabulary:

- Stable
- Transitional
- Phase-Locked
- Collapse
- Recovery

Reference hysteresis posture where applicable:

- ENTER when `φ < 0.60` for `P = 3`
- EXIT when `φ > 0.65` for `P = 3`

The frozen historical fixtures may contain earlier regime labels. Those fixtures are intentionally not rewritten.
