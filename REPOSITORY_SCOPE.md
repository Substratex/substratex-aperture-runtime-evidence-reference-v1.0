# Repository Scope

## Status

**Public reference architecture and conformance package** for **SubstrateX Aperture™**.

This repository documents the current public architecture of Aperture and preserves historical reference fixtures used during the evolution from the earlier Fieldglass / Telemetry Adapter research substrate into the current SubstrateX Runtime Evidence architecture.

## Included

- Current public scientific hierarchy: Intelligence in Motion™ → Longitudinal Computational Dynamics® → Longitudinal Computational Behavior.
- Evidence-Governed Computation™ integration and claim-boundary rules.
- Acquire architecture: Blackbox, Evidence Chamber, Validation Lab.
- Canonical Runtime, Current Evidence Run, Worldline, Runtime Evidence Authority, Passport, instruments, preservation.
- Public structural schemas and implementation maps.
- Frozen historical conformance, calibration, strict-role, and multi-turn fixtures.

## Not included

- Full production/prototype Aperture HTML/Vue application source.
- Proprietary instrument kernels or private calibration parameters.
- Private validation corpora.
- Hosted service infrastructure.
- Commercial deployment rights.

The absence of private implementation material does not change the status of the published architecture. This repository is intended to make the public evidence model, scientific hierarchy, test lineage, and implementation boundaries inspectable without distributing every proprietary component of the Aperture system.

## Historical compatibility

The frozen `test-suite/` predates the final LCD/EGC public hierarchy. Historical identifiers inside those fixtures are not current brand or scientific positioning. They remain unchanged because the fixtures are evidence of implementation lineage and expected behavior at the time they were created.
