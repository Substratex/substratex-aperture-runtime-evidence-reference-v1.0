# Schemas

These JSON Schemas expose **public structural envelopes**, not every private implementation field or proprietary detector/instrument kernel.

- `canonical-runtime.schema.json`
- `current-evidence-run.schema.json`
- `runtime-evidence-passport.schema.json`
- `runtime-evidence-artifact.schema.json`
- `zsf-evidence.schema.json` — legacy compatibility envelope retained for historical fixtures.

Schemas should be versioned when evidence-bearing structure or authority semantics materially change.
