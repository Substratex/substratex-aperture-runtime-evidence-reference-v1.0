# Telemetry Adapter v6.3 — Conformance Suite

## Purpose

This suite is the standards ratification harness for the runtime evidence ecosystem. It validates runtime QA, standards conformance, and deterministic replay.

## Test Layers

| Layer | Purpose |
|---|---|
| Runtime QA | Ensure the application functions correctly. |
| Standards Conformance | Ensure canonical semantics remain stable. |
| Evidence Replay Validation | Ensure same input produces same output. |

## Constitutional Invariant

```text
same input -> same output
```

## Semantic Invariants

The following must not drift without a formal standards revision:

- Basin Exit `final.basin_exit.t_star`
- Observable Failure `final.observable_failure.t_f`
- Lead-Time `final.lead_time.observed`
- Regime taxonomy: Stable, Transitional, Unstable, Collapse, Recovery
- Directional transition constraints
- ESL v2 envelope
- ZSF evidence structure
- Incident marker semantics
- Replay/provenance metadata

## Fixture Policy

Fixtures are canonical examples, not demos. They freeze expected behavior. If implementation output changes, one of two things is true:

1. A bug was introduced, or
2. A formal standards revision is required.

## Golden Artifact Policy

Golden artifacts are full ZSF exports generated by the canonical implementation. They must be compared byte-wise or semantically with future runs, excluding volatile fields such as `generated_at` and `run_id` unless deterministic fixture mode is enabled.

## Minimum Pass Conditions

- Parser accepts canonical fixture inputs.
- Compute runs without uncaught errors.
- ZSF validates required fields.
- `samples.length === meta.telemetry_samples`.
- Basin Exit and OF fields are internally consistent.
- ESL incident marker counts match `final.incident_markers.length`.
- Replay fixtures produce stable semantic outputs.

## Volatile Fields

The following fields may vary unless deterministic fixture mode freezes them:

- `meta.run_id`
- `meta.generated_at`
- marker `created_at`
- provenance signature timestamp

## Recommended Release Gate

No public release should be tagged unless this suite passes in full.
